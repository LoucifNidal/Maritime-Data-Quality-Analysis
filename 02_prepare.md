\# 02 — PREPARE



\## Data Source



\### Primary Source



\*\*NOAA Office for Coastal Management / U.S. Coast Guard AIS data\*\*



Dataset:



\*\*Nationwide Automatic Identification System 2025\*\*



NOAA describes this dataset as AIS broadcast-point data derived from the U.S. Coast Guard's national AIS receiver network. The 2025 data were filtered to a one-minute frequency and include vessel location and descriptive information. 



Official dataset:



https://www.fisheries.noaa.gov/inport/item/77594



\---



\# Dataset Fields



The working dataset contains 17 fields:



\- MMSI

\- BaseDateTime

\- LAT

\- LON

\- SOG

\- COG

\- Heading

\- VesselName

\- IMO

\- CallSign

\- VesselType

\- Status

\- Length

\- Width

\- Draft

\- Cargo

\- TransceiverClass



NOAA's documentation defines these fields as AIS vessel identification, position, movement, vessel characteristics, navigation status, cargo and transceiver information.



\---



\# Dataset Selection



The full 2025 AIS dataset was too large for a focused portfolio investigation.



A smaller geographic and temporal subset was therefore selected.
